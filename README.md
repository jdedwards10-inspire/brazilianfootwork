# Brazilian Footwork

Original responsive static website in black and yellow. Contact: Paulo@brazilianfootwork.com.

Open index.html to preview. No build or dependencies required. Enquiries open the visitor's email app; no form data is stored. Schedules, venues, ages, and pricing must be confirmed with Paulo.

All artwork is original SVG. No assets or source code were copied from the reference website.

GitHub Pages: Settings > Pages > Source > GitHub Actions. The included workflow deploys main.
